# Документация к Дашборду Финансовых Показателей

## Описание

Данный дашборд разработан для анализа основных финансовых показателей брендов в компании, занимающейся продажей товаров в сфере красоты. Он позволяет отслеживать ключевые метрики и выявлять проблемные сегменты для принятия стратегических решений.

## Основные Функции

### 1. Топ-10 Проблемных Сегментов

Дашборд предоставляет возможность построения Топ-10 проблемных сегментов при выборе соответствующих проблем в селекторе "Проблемы". Доступные фильтры:

- Рост выручки < 5 % и Выкуп < 95 %
- Рост выручки < 5 %
- Выкуп < 95 %
- Рост выручки < 5 % или Выкуп < 95 %
- Нет проблем
- Не выбрано (нет фильтра)

### 2. Рекомендации

Для каждого проблемного сегмента и отдельных наименований товаров (SKU) предоставляются рекомендации. При нажатии на любой сегмент в таблице "Детализация за месяц" (Бренд, Предмет, Категория или Страна) добавляется поле 'SKU', что позволяет получить детализированные рекомендации.

## Ключевые Метрики

- **Общая выручка**
- **Продажи**
- **Средняя цена товара**
- **Процент выкупа товаров**

## Динамика и Детализация

- **Динамика за полгода**: Отображает изменения выручки, продаж и процента выкупа.
- **Детализация за месяц**: Позволяет анализировать данные по брендам, предметам, категориям и странам.

## Использование

Дашборд предназначен для использования менеджерами продукта, бренд-менеджерами, аналитиками и маркетологами. Он обеспечивает удобный доступ к актуальной информации и служит инструментом для презентации данных на ежемесячных встречах с руководством.

## Пример Использования

1. Выберите интересующую проблему в селекторе "Проблемы".
2. Проанализируйте Топ-10 проблемных сегментов.
3. Ознакомьтесь с рекомендациями для улучшения показателей.
4. Используйте данные для разработки стратегий и принятия решений.

## Заключение

Данный дашборд является мощным инструментом для анализа и оптимизации ассортимента, а также для принятия обоснованных решений по улучшению финансовых показателей компании.
